# Проверка архитектуры промпта

Это платный прогон на модели мастера из конфигурации сервера. В pytest внешних
вызовов нет. Набор содержит 20 реплик, поровну для Шира и станции без магии.

Снимок Шира снят из тестовой кампании `c_169836e8c8cf8520` 30 октября 2026 года.
Герой уже в общем зале, поэтому переходы проверяются из зала в кухню, подвал
и на задворки. Фикстура станции составлена вручную. После базового замера
фикстуры и ожидания нужно сохранять неизменными для сравнения этапов.

Запускать в окружении сервера с ключами провайдера и установленными зависимостями:

```powershell
python -m tests.eval.run --n 5 --save
python -m tests.eval.run --n 5 --output tests/eval/prefix-result.json
```

`--save` создаёт исходный `baseline.json`, существующие отчёты не перезаписываются.
`--cases station_wait,shire_speech --n 1` позволяет проверить отдельные случаи,
но такой прогон не сопоставим с полным baseline. Сравнение требует одинаковых
модели, фикстур, набора случаев и числа повторов. Допустимое снижение доли
успехов — 5 процентных пунктов; ошибки провайдера не дают пройти ворота.

Сохраняются исходный IntentV2, нарушения, размер каждой части в символах,
токены входа и кэша (неизвестный кэш остаётся `null`), стоимость и задержка.
Счётчик символов включает JSON-разделители, но не служебную разметку провайдера;
это не оценка токенов. Набор проверяет один ответ разбора, без серверного repair,
проверки смысла и рассказчика. Поэтому он не доказывает художественное качество
и не заменяет интеграционные тесты и ручную игру.

Проверки применяют `clean_model_intent` и схему `IntentV2`, но явно ошибочный
`resolution` оценивают до нормализации, чтобы видеть необоснованные броски
в чистой речи. Цитаты всегда проверяются по словам игрока в текущем случае.

На момент добавления прогонщика `baseline.json` ещё не создан: автоматическая
проверка разрешений заблокировала передачу снимка кампании провайдеру DeepSeek
для платных вызовов до уточнения разрешения владельца. Оптимизации из задач
4–10 не начинались; базовый замер должен предшествовать им.

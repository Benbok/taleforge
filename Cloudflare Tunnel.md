Как запустить

Если файла .env ещё нет, скопируй .env.example в .env и задай SUPERADMIN_PASSWORD и JWT_SECRET (openssl rand -hex 32). Без секрета все выходы из аккаунта будут сбрасываться при каждом перезапуске.
docker compose --profile tunnel up -d --build
docker compose logs tunnel и найди в выводе строку вида https://что-то-случайное.trycloudflare.com. Это и есть адрес для друзей.
Пропиши его в .env как PUBLIC_URL=https://…trycloudflare.com и перезапусти только приложение командой docker compose up -d app. Без этого ссылки-приглашения будут вести на localhost.
Создай приглашения в кабинете кампании и разошли ссылки.

Учти одно: адрес быстрого туннеля меняется каждый раз, когда перезапускается контейнер tunnel. Поэтому перезапускай только app, а если туннель всё же перезапустился, повтори шаги 3–4. Голосовые реплики через туннель работают, потому что микрофону нужен https, а туннель его даёт.

Запасной вариант: ngrok. Нужна бесплатная регистрация, зато на бесплатном тарифе дают один постоянный домен, и PUBLIC_URL не придётся менять. Запуск: ngrok http 8000 --url=твой-домен.ngrok-free.app. Минус в том, что при первом заходе друзья увидят страницу-предупреждение ngrok, и её нужно прокликать. Если хочешь постоянный адрес без этого предупреждения, то можно взять именованный туннель Cloudflare на своём домене, но для этого нужен домен, подключённый к Cloudflare.

# Tabletop Audio в Taleforge

В библиотеку добавлены 16 оригинальных MP3 с [Tabletop Audio](https://tabletopaudio.com/), автор — **Tabletop Audio**.
Каждая композиция длится около 10 минут. Всего около 220 МиБ. Скачаны 2026-10-12 с официального домена
`sounds.tabletopaudio.com`; файлы не обрезаны, не ремикшированы и не перекодированы.

некоммерческих целей с указанием автора и лицензии; распространение переработанных записей ограничено лицензией.
Для коммерческого использования в игре нужна отдельная договорённость с автором (`gm@tabletopaudio.com`).
Разрешение автора на коммерческие подкасты/видео через Patreon само по себе не разрешает использование в игре.

Звуки SoundPad и закрытые альтернативные версии Patreon в этот набор не входят. Изображения сайта не импортированы.

## Использование

Карточки находятся в `audio/tracks.yaml`, имеют префикс `tta_`, вид `music` и доступны всем мирам.
Движок выбирает их обычным способом по настроению и тегам места; музыка, привязанная к конкретному миру,
сохраняет существующий приоритет при прочих равных. ИИ-мастер использует обычный инструмент `set_music`.
Владелец включает звук в настройках кампании, а каждый игрок нажимает «Включить звук» в игре.
Кнопка «Сменить трек» выбирает другую подходящую дорожку.

В панели звука рядом с текущей музыкой показываются автор, ссылка на источник и лицензия. Эти сведения
сохраняются при редактировании карточки и привязке к миру в админке. Треки можно выключить в админке «Звук».

Клиент получает MP3 через существующий API с Bearer-авторизацией. Полный сжатый файл скачивается перед
воспроизведением, затем браузер декодирует его по мере проигрывания через `HTMLAudioElement` и Web Audio.
Он не помещается в кэш декодированных эффектов. При смене музыки и выходе из игры объектные URL и
узлы громкости освобождаются. Два аудиоэлемента разблокируются по нажатию «Включить звук» и переиспользуются
для плавных переходов, чтобы автоматическая смена трека работала при ограничениях autoplay в Safari.
При выходе из игры освобождаются и они. Плавная смена, позиция по часам сервера и приглушение под голос сохраняются.
Первый запуск на медленном соединении может ждать загрузки файла размером около 14 МиБ; API разрешает
длительное кэширование неизменившихся файлов браузером.

`tabletop-audio-manifest.json` содержит официальные ссылки скачивания, SHA-256, размер, длительность и
параметры каждого файла. Он фиксирует происхождение набора; для работы плеера достаточно MP3 и карточек.

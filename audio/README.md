# Библиотека звука

Треки для звукового сопровождения ИИ-мастера. Всё в одной папке: файлы и `tracks.yaml` с карточками.
Админка «Звук» пишет сюда же. Файл без карточки — «неразобранный»: в игре он не звучит, пока его не разберут в админке.

Сервер читает папку из `AUDIO_DIR` (по умолчанию эта папка; в docker compose она подключена на запись## Два вида

| Вид | Что | Как играет |
|---|---|---|
| `music` | фоновая музыка | петля, одна на сцену; движок выбирает трек по настроению сцены и месту |
| `sfx` | эффект на 1–6 секунд | один раз: движок — на событие из `cue`, мастер — эффекты без `cue` |

Мастер только называет настроение (`set_music`), трек подбирает движок: сначала по настроению, потом по месту.
Бой движок ведёт сам: в начале — музыка с настроением `battle` и эффект `combat`, в конце — музыка места и `victory`.
За ход звучит не больше двух эффектов, важные первыми. Недавно звучавшие треки движок не повторяет подряд, а из
равных берёт случайный. Владелец кампании может нажать «Сменить трек» в игре, если музыка не легла.

## Карточка

```yaml
- id: mel_rest             # латиница, цифры, _ и -; админка берёт из имени файла
  file: mel_rest.ogg       # файл в этой папке
  layer: music             # music | sfx
  title: "Тёплый отсек"    # видят игроки
  moods: [calm, warm]      # музыка: calm warm mystery wonder dread horror sorrow tension chase battle heroic triumph
  places: [tavern, camp]   # музыка, необязательно: в таких местах трек предпочтительнее
  cue: [death, secret]     # эффект: события, на которые он звучит сам (одно или список)
  packs: [echo-leviathans] # пусто — общий трек; иначе только для этих миров
  gain_db: -3              # необязательно: выравнивание громкости
  off: true                # временно выключить
```

События `cue`: `combat` начало боя, `victory` победа, `death` гибель героя, `act` новый акт сюжета, `secret` раскрыта
тайна, `levelup` новый уровень, `place` отряд впервые пришёл в место, `crit` критический успех, `fumble` критический
провал, `kill` враг повержен, `spell` заклинание, `hazard` опасность, `effect` наложено состояние, `hit` попадание,
`rest` отдых. На одно событие можно повесить несколько
эффектов — звучит случайный. Старые карточки со слоями `rhythm` и `ambience` и полями `bpm`, `bars` читаются: такие
треки считаются музыкой.

## Файлы

OGG (Vorbis или Opus) — лучше всего: петля без щелчка на стыке; MP3, WAV и M4A тоже играют. До 20 МБ на файл. Список треков для подготовки с подсказками генератору —
`design/audio-tracklist.md` в папке проекта.

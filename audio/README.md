# Библиотека звука

Треки для звукового сопровождения ИИ-мастера. Всё в одной папке: файлы и `tracks.yaml` с карточками.
Админка «Звук» пишет сюда же. Файл без карточки — «неразобранный»: мастер его не слышит, пока ему не назначат слой.

Сервер читает папку из `AUDIO_DIR` (по умолчанию эта папка; в docker compose она подключена на запись).

## Слои

| Слой | Что | Как играет |
|---|---|---|
| `music` | мелодия, без ударных | петля, одна в слое |
| `rhythm` | только перкуссия | петля, вступает по такту мелодии |
| `ambience` | шум места, без музыки | петля |
| `sfx` | эффект на 1–6 секунд | один раз, вместе с текстом мастера |

## Карточка

```yaml
- id: mel_rest             # латиница, цифры, _ и -
  file: mel_rest.ogg       # файл в этой папке
  layer: music             # music | rhythm | ambience | sfx
  title: "Тёплый отсек"    # видят игроки
  hint: "тёплый покой: отдых, лагерь, таверна"   # одна строка для мастера
  moods: [calm, warm]      # calm warm mystery wonder dread horror sorrow tension chase battle heroic triumph
  places: [tavern, camp]   # свободные метки мест
  bpm: 100                 # мелодия и ритм: темп; у пары он должен совпадать (или отличаться вдвое)
  bars: 16                 # длина петли в тактах 4/4 — по ней ритм входит точно в такт
  gain_db: -3              # выравнивание громкости
  packs: [echo-leviathans] # пусто — общий трек; иначе только для этих миров
  cue: victory             # только sfx: victory | death | secret — движок играет сам
  off: true                # временно выключить
```

Мастер видит сначала треки своего мира, потом общие. Боевой ритм (`rhythm` с настроением `battle`) сервер
включает сам, если мастер начал бой без него.

## Файлы

OGG (Vorbis или Opus) — лучше всего: петля без щелчка на стыке. Петли без вступления и затухания, мелодия и ритм —
ровно 16 или 32 такта. До 20 МБ на файл. Список треков для подготовки с подсказками генератору —
`design/audio-tracklist.md` в папке проекта.

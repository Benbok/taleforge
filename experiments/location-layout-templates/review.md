# Итоговое ревью экспериментальной коллекции

Коллекция содержит 12 воспроизводимых заготовок: шесть архетипов по два варианта. Статус — пригодна для следующего этапа проектирования подбора и адаптации. Автоматическое использование мастером ещё не подключено.

## Результат визуального отбора

| Шаблон | Сильная сторона | Ограничение |
|---|---|---|
| tavern_roadside | Зал, кухня и спальни разделены; центральные маршруты свободны | Стойка и столы используют общую категорию furniture |
| tavern_urban_cellar | Два уровня, кабинет и отдельный тайник | Требуется переключение уровня; авторский обзор раскрывает тайник |
| temple_compact_shrine | Алтарь и ряды колонн создают выраженный центр | Прямоугольный неф без апсиды |
| temple_ruined_courtyard | Двор, разрушенный неф и крипта различаются материалом и уровнем | Разрушение показано деталями, контуры стен остаются регулярными |
| cave_passages_grotto | Узкий тоннель, большой грот и видимое озеро | Озеро оформлено отдельным участком |
| cave_multilevel_grottos | Вертикальный переход и затопленный нижний карман | Нижний водоём отдельный; мокрая чаша в гроте обозначена каменным объектом |
| forest_clearing_trail | Тропа и ответвление к чаще читаются | Тропа прямая; лес представлен условными деталями |
| forest_stream_crossing | Ручей пересекает дорогу с мостом | Берега и дорога регулярные, естественные изгибы не поддерживаются |
| port_quay_warehouse | Пирс между водными участками, склад и каменная набережная | Берег угловатый; воду можно посещать как участок без отдельной механики плавания |
| port_fishing_pier | Берег, хижина, мостки и видимая акватория | Вода только с одной стороны мостков |
| ruins_manor_estate | Парк, Г-образный зал и уцелевший кабинет | Обрушенные стены условны |
| ruins_watchpost | Двор, круглая башня и подземный каземат | Бойницы декоративные, стрельба через них автоматически не реализована |

Это схематичные тактические карты. Они различимы по структуре и материалам, но не являются художественными battlemap. Оценки 5/5 прежнего отчёта не считаются подтверждёнными.

## Воспроизводимость и механика

Исходник — scripts/build_templates.py. intent.json и blueprint.json сохраняют результат сборки. Проверены seed 1, 7, 42, 99, 123 для всех 12 шаблонов.

Обычный geometry.build_area сохраняет твёрдые детали одновременно в walls (движение и видимость) и features (имя, категория и рисунок). Renderer не дублирует заливку стены под видимой твёрдой деталью. Декорации не дают автоматических бонусов укрытия, добычи или опасностей. Вода — визуальный материал.

Внутренние exits.to разрешены через ID участков. previews/player_view.svg — иллюстративное состояние с текущим участком и выбранными запомненными соседями, а не подтверждение реального посещения игроком. Секретные участки исключены. previews/overview_level_*.svg — авторские планы каждого уровня; previews/area_*.svg — отдельные участки.

Сборка завершится ошибкой при провале любого seed. Регрессионные проверки находятся в tests/test_experiment_layout_catalog.py.

## Проверки

178 backend-тестов коллекции, геометрии и качества прошли. Сборка всех шаблонов и экспорт SVG завершились успешно. Frontend ранее прошёл 226 тестов и проверку TypeScript после изменения renderer; последующая доработка затрагивает только экспериментальные данные и экспорт превью.

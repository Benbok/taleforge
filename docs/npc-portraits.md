# Портреты встреченных NPC

Откройте карточку персонажа по ссылке в рассказе или с карты. Владелец стола, мастер или администратор с обычным правом видеть этого NPC может нажать «Создать портрет». Генерация локальная, через ComfyUI; русский публичный текст переводится технической моделью. Секретные заметки, мотивы, боевые данные и скрытые личности в промпт не передаются.

Новый портрет сначала становится вариантом. Его можно открыть на весь экран внутри приложения и нажать «Применить» под миниатюрой. После выбора остаётся только выбранный портрет: предыдущие варианты скрываются у всех участников, в том числе после перезагрузки. «Создать ещё вариант» показывает новый портрет рядом с текущим для сравнения. Сбой генерации сохраняет выбор. Обычные участники просматривают общий портрет и доступные варианты, не меняя выбор. Время выбора хранится в `chosen_at` (миграция `universal_0016`); файлы отклонённых вариантов не удаляются.

Доступ совпадает с карточкой знаний. Неизвестный/чужой NPC недоступен даже по прямой ссылке. Для NPC вне поля зрения берётся снимок реальной встречи, а не его изменившаяся текущая внешность. Снимки видимых NPC сохраняются обычным observe при входе/раскрытии, а также при явной генерации портрета находящегося рядом NPC (для встреч до включения функции). NPC без размещения не создаёт участникам фиктивную встречу. Отсутствие снимка старой встречи не заменяется догадкой о внешности.

Попытки и ручной выбор хранятся отдельно (`npc_portraits`, `npc_portrait_selections`, миграция `universal_0015`). Область общего изображения: стол + NPC + доступное описание. Изменение описания не раскрывает новый вид персонажа по старому портрету. Уникальная активная попытка, request_key, сроки аренды и повторная проверка описания защищают от дублей, зависших работ и публикации устаревшего результата. Оригиналы и WebP-миниатюры находятся в `MEDIA_DIR/npcs`, доступны только с авторизацией.

Включение: `NPC_PORTRAITS_ENABLED=1`. Используются `PORTRAIT_COMFYUI_URL`, `PORTRAIT_COMFYUI_WORKFLOW`, `PORTRAIT_COMFYUI_TIMEOUT_SEC`, техническая модель выбранного `LLM_PROVIDER`. В локальном compose рабочей копии включено. Учёт: `npc_portrait` и `npc_portrait_translation`, фаза creation. Изменяется только художественное представление; игровое время и параметры NPC не меняются.

По указанию пользователя новые локальные картинки используют общее художественное направление: рисованное фэнтези, заметные мазки/фактуры, стилизованные формы и атмосферный свет. Направление стоит в начале промпта; репозиторные workflow исключают фото, фотореализм и 3D-рендер. Это применяется к NPC, героям, локациям и снаряжению; уже сохранённые картинки автоматически не заменяются. Используется установленная RealVisXL, новые модели не скачивались.

Проверка:44 целевых backend-теста (включая восстановление после истечения аренды, одновременные запросы, память встречи, неизвестного/неразмещённого NPC, миграции и прежние изображения);422 frontend-теста, сборка и ruff. Настоящий API создал два варианта встреченных пещерных крыс, второй — в рисованном стиле (34,7с полного browser-прогона). Выбор не изменялся. Native-браузер с настоящими EntityPopover/API проверил полный экран, клик внутри portal, Esc с сохранением родительской карточки и мобильную ширину. Превью: `.superpowers/npc-portrait-preview.png`. Временный файл авторизации удалён помощником.

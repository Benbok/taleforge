# Проверка архитектуры промпта

Независимый обзор выполнен отдельным агентом по плану и спецификации. Обзор был
только для чтения, без платных вызовов модели и изменения живой базы.

## Исправленные замечания

| Замечание | Исправление | Доказательство |
|---|---|---|
| Нормативный запрет за пределами сводки или бюджета отсутствовал у проверки смысла | laws, powers и world передаются проверке целиком как блоки | Тест с длинным абзацем и запретом в конце сначала упал для всех трёх полей, затем прошёл |
| Сбой после последнего need_lore позволял восстановлению выполнить запасное действие | Атомарное сохранение отказа; исчерпанное восстановление возвращает тот же отказ без действия | Тест нормального и восстановленного пути сначала выявил различие, затем проверил отсутствие proposal и новых вызовов |
| Граница истории по умолчанию переполняла PostgreSQL int32 | Используется фактический максимальный Message.seq вместо int64-сентинела | Найдено при живой проверке; тест RED→GREEN |

Небольшое отложенное замечание: некорректные вручную собранные снимки с `null`
вместо списков или строк требуют нормализации. Канонический сборщик живого хода
передаёт корректные типы; обычные пустые миры проверены.

## Решения исполнителя

| Решение и основание | Цена решения, если предположение неверно |
|---|---|
| Использовать существующий worktree universal-retirement, где лежат план и спецификация; сохранить посторонний арт | Результат остаётся в существующей feature-ветке, а не в отдельной новой ветке |
| Использовать Python-окружение основного checkout, поскольку в worktree нет .venv; явный PowerShell обходит ошибку запуска песочницы | Версии зависимостей могут отличаться от контейнера; платные замеры и живая игра выполнялись именно в контейнере |
| Снять фактический общий зал Шира, не перемещая героя к первоначальному входу ради фикстуры | Изначальная формулировка входа в трактир не покрыта этим снимком; закрытая дверь покрыта станцией |
| Передавать явные upto_seq и audience для полного совпадения истории живого хода | Отдельный снимок не воспроизводит произвольный исторический момент без этих параметров |
| Оценивать явный raw resolution до нормализации, как требует тест чистой речи | Оценка строже фактического серверного поведения |
| Включать combat для явной атаки/лечения/защиты и magic для действующих эффектов и известных способностей | Немного больше правил для некоторых ходов; сохраняются атака нейтральной цели и снятие формы |
| Нарезать на границе сообщения, сохраняя полный контекст валидатору и восстановлению | Новые клиенты должны пользоваться decide_messages, чтобы получить нарезку |
| Убирать копии лора из context.world, иначе они обходят бюджет world_rules | Новым студийным полям потребуется явный нарезчик или включение в индекс |
| Передавать все нормативные laws/powers/world проверке смысла вне бюджета | Проверка длинных сводов правил остаётся дорогой; это сохраняет независимую проверку допустимости |

## Границы доказательства

Посторонние изменения арта, портретов и интерфейса исключены из этой работы.
Литературное качество и реальная смена провайдера не доказываются автономным
обзором; проверены конструкция запроса, интеграционные тесты и три реальных хода
на DeepSeek. Гейтинг наград следует плану, но набор не содержит случаев наград —
их стоит добавить при следующем расширении оценки.

Измеренные запросы разбора после исправлений обзора совпали по хэшам для всех
двадцати случаев с финальным отчётом. Исходные 70/100 сохранены в
`tests/eval/baseline-original.json`; итоговые 74/100 приняты как новая база.

Финальный полный прогон после исправлений: **2667 passed, 24 skipped** за 705,82 с,
один информационный warning зависимости Pydantic. Ruff check и format --check
проходят для всех 27 Python-файлов изменения. AST-граф обновлён: 13742 узла,
38243 ребра. Финальный образ пересобран и запущен, HTTP отвечает 200; в живом
контейнере дополнительно проверено наличие полного длинного нормативного правила
в контексте проверки смысла.

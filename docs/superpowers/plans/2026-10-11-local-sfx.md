# Local SFX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Локальная генерация, сохранение подписанных SFX, повторное использование и управление через настройки без задержки ходов.

**Architecture:** Устойчивые задания и версии в текущей БД, отдельный inference процесс, один существующий микшер. Campaign-scoped cache и адресная одноразовая доставка после публикации хода.

**Tech Stack:** FastAPI, SQLAlchemy/Alembic, asyncio subprocess, Stable Audio 3 (изолированная установка), ffmpeg, React/TypeScript, pytest/Vitest.

**Spec:** ../specs/2026-10-11-local-sfx-design.md

## Global Constraints

- description 8–300, duration 1–4 сек., request_sfx ≤1 за ход, все SFX ≤2 за ход.
- Inference вне event loop/транзакции; concurrency=1; CPU default; bounded queue, retries и timeout.
- Не изменять ручной tracks.yaml и исходы игровых действий; сохранить пользовательские правки.
- Immutable файлы и версии, авторизация кампании, локальные offline веса.

## Review Focus

- Rollback и checkpoint/recovery: задача не рождается после отката, звук не опережает текст.
- Split party/move/rejoin: запоздалый результат не уходит другой группе.
- Два concurrent cache misses/worker restart: одна активная задача, lease и ограниченные повторы.
- Regeneration failure/квота: старая версия доступна, файл не публикуется до commit.
- Audio decode race/autoplay/mute: повтор, поздняя загрузка и уход из сцены не проигрывают звук.

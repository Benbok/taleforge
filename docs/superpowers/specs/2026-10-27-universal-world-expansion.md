# Universal world expansion

User-approved intent: an author provides lore/laws/start, not an exhaustive location list. The master develops persistent scenes during play. A tunnel described in the opening must become an actual passage leading to a lazily prepared destination before the hero crosses it. Preserve the existing campaign, originals, receipts and map style.

Architecture: closed scene-plan and independent semantic review; stable server IDs and bounded objects/passages; reuse WorldGenerationState location_initial phases tagged universal-scene-v1, existing leases/budgets/CAS/recovery and LlmCall accounting. Add a session-level phase commit hook so Universal never opens the legacy runtime/catalog. Preparation is outside action transactions and cannot spend a game step. Current public facts are immutable foundations, generated secret entities/passages stay hidden; no other hero private data enters generation. A pending destination is not enterable. Prepared descriptions/links/entities persist once; returns/retries reuse them.

Authored Universal games enable development by adventure version (explicit setting can opt out for controlled fixtures). New session framing prepares the entry; already-running games prepare on their next action. Scene preparation has a bounded generation/review repair budget, durable validated draft and recoverable failures, no partial publication. Existing authored non-Universal phases remain compatible. Initial actors/resources/clock are preserved during preparation. Movement must bind a saved destination or explicitly remain within the scene; unresolved crossing must not become a successful no-op/free note. Narrow destination narration recipients to colocated original audience, without leaking destination contents to left-behind heroes.

Implementation choices: scene plans supply ordinary props, NPCs/creatures, bounded visible or hidden passages. Visible passages create stable unprepared destination stubs with known public hints; full contents are generated on entry. No rewrites of prepared rooms, no arbitrary foreign links, no template/SRD dependency, no grants to hero budgets/items. Reuse Universal creature initialization and physical-prop contracts. Map geometry stays optional; public directions become structured saved links and UI projection reuses them.

Acceptance: old single-room campaign -> current scene materialized -> known tunnel -> target prepared -> one committed movement -> grounded description/map -> return without regeneration. Provider failure/crash/concurrent workers, action retry, split party, hidden data, world-law review, inventory/original preservation, live schema upgrade compatibility. Scripted providers only; deploy same combined runtime and let the user issue the next live command.

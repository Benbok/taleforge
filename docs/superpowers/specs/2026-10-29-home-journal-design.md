# Главная: журнал приключений

Согласовано в чате: выразительная карточка продолжения, компактные остальные столы, небольшой блок героев. Тёплая палитра, медные акценты, адаптация к светлой и тёмной теме и мобильным экранам.

Вместо подписи о 5e показывать мир и закреплённую версию: для авторских миров — публичное название опубликованной AdventureVersion и её номер; для контентных пакетов — название и версию пакета. Не брать текущий редактируемый проект. При отсутствии мира использовать нейтральную подпись без выдуманной версии.

Первой показывать доступную незавершённую сессию, затем последнее посещённое активное приключение. Не дублировать выделенный стол в общей сетке; ролевые фильтры должны учитывать его. Сохранить переходы к созданию героя, управлению и игре и текущие ограничения доступа.

Убрать вымышленные новости, шкалу резонанса, бегущую строку и большой блок создания кампании. Кнопка «Новое приключение» рядом с заголовком. Футер: «Taleforge · Ваши миры. Ваши истории.» и ссылка на студию для авторов.

Подходы: косметическая замена текстов не решает проблему различимости столов; отдельная новая система навигации избыточна. Выбран редизайн существующей главной с сохранением вкладок и маршрутов. Вкладка миров использует реальные данные API и явно сообщает об ошибке или пустом каталоге вместо резервных миров 5e.

Рабочая копия по указанию пользователя: `.worktrees/universal-retirement`, ветка `feature/universal-retirement`. При переносе сохранить её каталог `/api/adventures/catalog`, прямой запуск опубликованных миров, вкладки через `?tab=worlds|heroes` и защищённые портреты героев. Новое приключение начинается с выбора мира в этом каталоге. Типы персонажей остаются универсальными, без старых классов 5e.

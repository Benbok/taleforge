# Приёмка подключения каталога

Реализация в main, рабочая копия .tmp/main-push. Каталог состоит из 12 JSON
ресурсов, не импортирует экспериментальный генератор. Снимок сохраняется
в reservation; executor проверяет мандат повторно и использует прежний fallback.

## Уточнения плана

- Подбор использует объявленные ref bindings и ограничения SpatialPlan.
  Отдельного поля role в SpatialPart нет; неизвестные refs не угадываются по тексту.
- Контекст передаётся из plan, Mandate остаётся прежнего формата.
- Диагностика размещена в result_manifest source/template_fallback и не меняет
  quality при отказе шаблона. Метрики задержки доступны через существующие
  записи фаз; общий runtime кампании не измерялся.
- Добавлен доступ к флагу через PATCH кампании и обновлены API-контракты.
- Поля ресурса version и checksum фиксируют исходную запись. В reservation
  сохраняется уже адаптированный intent; checksum не является подписью данных.

## Покрытие стандартных мандатов при seed=42

| Тип | Результат | Причина/шаблон |
|---|---|---|
| tavern | fallback | состав уровней или неподтверждённый тайник |
| temple | template | temple_compact_shrine |
| cave | fallback | ограничения формы частей |
| forest | template | forest_clearing_trail |
| port | template | port_quay_warehouse |
| ruins | fallback | ограничения формы/окружения |

Низкая доля совпадений — ожидаемое ограничение первой поставки. Согласование
дополнительных шаблонов с мандатами нужно делать в каталоге, без ослабления
проверок обязательных частей. Поддержка уже созданных карт не меняется.

## Проверка реализации

247 тестов каталога, геометрии, spatial, store и экспериментальных ресурсов
прошли; отдельно 38 проверок API, layout model/plan и шаблонной интеграции.
Сценарий разворота локации из каркаса кампании тоже прошёл: шаблон применяется
без layout-вызова модели. Frontend: 226 тестов, TypeScript без ошибок; Ruff чистый.

Полный набор layout-тестов остановился на ожидании map.state в
test_layout_ahead.py::test_prepared_neighbour_stays_unknown_to_players.
Таймаут воспроизведён на исходном коммите 3c24460 в отдельной рабочей копии
без нового подключения каталога. Полный набор не заявляется прошедшим.

Независимое ревью нашло порядок ограничения кандидатов: исправлено, теперь
совместимость фильтруется перед ранжированием и лимитом трёх геометрических
попыток. Добавлен regression test с четырьмя кандидатами.

# Документы Taleforge

Проектные документы игры и мира «Эхо Левиафанов». Если текст расходится с кодом или пакетом `content/echo-leviathans/`, прав канон мира, а данные пакета подтягиваются к нему.

## Приложение

- [tz-ai-master.md](tz-ai-master.md) — техническое задание «AI-Мастер»: архитектура, правила, инструменты мастера, память, пакеты контента. Копия документа из Claude Docs (ревизия 42).
- [campaign-preparation.md](campaign-preparation.md) — подготовка кампании: анкета, сюжетный каркас, вступление, характер мастера.
- [interface-stage7.md](interface-stage7.md) — план этапа 7 «Интерфейс». Макеты экранов лежат в [stage7/](stage7/).

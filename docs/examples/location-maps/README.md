# Примеры карт локаций

JSON-файлы — полный ответ `map.state` (`MapState`), который получил бы игрок, а SVG рядом с
ними нарисованы игровым компонентом `LocationMapSvg` из поля `location_map`. Python-экспорт
поднимает временную SQLite, строит пилотный комплекс через provider, validation и geometry,
сохраняет наблюдения двух героев и вызывает настоящий `party_map`. Время наблюдения
(`observed_at`) в файлах обнулено, время создания мест зафиксировано, поэтому повторный
экспорт даёт те же файлы. Обновить их можно командами:

```text
uv run python tools/export_location_map_examples.py
cd web
npm run map:examples
```

- `temple-known` — первый герой в круглой ризнице (маска со срезанными углами). Дорога и
  главный зал, которые он уже видел, показаны приглушённой памятью. Тайная дверь в тайник не
  раскрыта и в ответ не попадает.
- `field-stream-bridge` — тот же герой на лугу с ручьём и мостом. Дорога, зал и ризница
  остаются запомненными участками.
- `hero-memory` — второй герой на дороге. Он видел только её, поэтому на его карте нет
  участков, которые открыл первый герой.

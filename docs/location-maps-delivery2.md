# Генеративные карты локаций, поставка 2

Поставка реализует визуальную карту комплекса поверх серверного `MapLocationPlan`.
Открытые участки компонуются в одном SVG с уровнями, маской поля, материалом,
краями и рельефом. Дорога, ручей и мост рисуются из `terrain`; широкие проходы
используют все клетки `cells`.

Для каждого героя хранится `MapMemory`: снимок участка и раскрытые проходы. Текущий
участок обновляется наблюдением при событии и перемещении, а раскрытие мастером
выдаётся выбранным героям. Тайные участки не попадают в проектор до раскрытия.

Клиентская карта обрабатывает `map.traverse`: одна кнопка создаёт запрос с
`request_id`, повторный клик блокируется, устаревший ответ игнорируется. Сервер
проверяет исходное место перед подготовкой и повторно проверяет его при завершении;
ошибка чтения зрителя всё равно возвращает `map.traverse.result`.

Примеры JSON/SVG находятся в [docs/examples/location-maps](examples/location-maps/README.md).
Обновление выполняется `uv run python tools/export_location_map_examples.py`, затем
`cd web && npm run map:examples`.

## Проверка

- `uv run ruff check` и `ruff format --check` для изменённых Python-файлов;
- `npm run typecheck`, `npm test`, `npm run build` и `npm run map:examples` в `web`;
- серверный полный прогон `uv run pytest -q -n auto -rs`.

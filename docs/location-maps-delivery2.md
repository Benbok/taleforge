# Генеративные карты локаций, поставка 2

Поставка реализует визуальную карту комплекса поверх серверного `MapLocationPlan`.
Открытые участки компонуются в одном SVG с уровнями, маской поля, материалом,
краями и рельефом. Дорога, ручей и мост рисуются из `terrain`; широкие проходы
используют все клетки `cells`.

Для каждого героя хранится `MapMemory`: снимок участка и раскрытые проходы. Участок, где
стоит герой, обновляется наблюдением при событии; при уходе герой уносит последнее увиденное
состояние, а изменения после ухода в память не попадают. Раскрытие тайного прохода мастером
(`edit_sketch reveal`) выдаёт личное знание присутствующим героям. Оно действует с обеих
сторон прохода и переживает повторное `hide`; остальные герои секретного прохода не видят.
Откат памяти пишется в общем формате журнала: новая строка — `delete`, изменённое поле —
`{table, id, field, before}`.

`MapWindow` рисует карту через `LocationMap`: масштаб и сдвиг, текущие токены, стены,
объекты и их осмотр, выбор прохода в `PassageBar`. Клики по клеткам, токены и подход к
проходу переводятся в механические координаты от одного и того же живого строя отряда.
Запомненные участки приглушены и не запускают переход. `map.get` несёт `request_id` и
`as_seat`; при смене героя, кампании или сокета клиент сбрасывает карту.

Клиентская карта обрабатывает `map.traverse`: одна кнопка создаёт запрос с
`request_id`, повторный клик блокируется, устаревший ответ игнорируется. Сервер
проверяет исходное место перед подготовкой и повторно проверяет его при завершении;
ошибка чтения зрителя всё равно возвращает `map.traverse.result`.

Примеры JSON/SVG находятся в [docs/examples/location-maps](examples/location-maps/README.md).
Обновление выполняется `uv run python tools/export_location_map_examples.py`, затем
`cd web && npm run map:examples`.

## Проверка

- `uv run ruff check` и `ruff format --check` для изменённых Python-файлов;
- `npm run typecheck`, `npm test`, `npm run build` и `npm run map:examples` в `web`;
- серверный полный прогон `uv run pytest -q -n auto -rs`.

Последний прогон после исправлений ревью: backend — 842 passed, 2 skipped (нужен
PostgreSQL); frontend — 142 passed, typecheck и build проходят; повторный экспорт
примеров даёт те же файлы.

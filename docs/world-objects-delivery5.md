# Генерация исследуемых сцен — поставка 5: техническая модель

**Спецификация:** [2026-10-11-explorable-scene-generation-design.md](superpowers/specs/2026-10-11-explorable-scene-generation-design.md), редакция 2, §3, §4.2, §4.3, §6.3, §9.
**Объём:** только поставка 5. Интерфейс и явное включение — поставка 6.

## 1. Что было

Подготовка (поставки 3–4) работает только детерминированно: имена обстановки и контейнеров берутся из профиля,
находки называются по шаблону. Счётчик `llm_attempt_count` в строке фазы есть, но не используется.

## 2. Решения

- `app/agents/world_generator.py` — адаптер технической модели (`parser_model_for`, как у эскиза). Он зависит
  только от контрактов и не пишет `Entity`. Модель получает минимальный снимок (§4.2): место, контейнер, тон
  профиля, что уже стоит в месте, и слоты плана. Тайный каркас в снимок не входит.
- Строгая схема ответа `submit_scene`: `objects[] = {slot_ref, name, description}`, `slot_ref` из перечня
  слотов плана, `additionalProperties: false`. Роль, шаблон, количество и носитель сюжета модель задать
  не может: они берутся из плана. Ответ проходит ту же проверку, что и детерминированный. Имя сюжетного
  носителя менять нельзя, механические слоты обязательны.
- Лимит — 2 вызова за всю жизнь фазы: один вызов и одна корректирующая попытка. Вызов занимается до
  сетевого запроса условной записью строки фазы (`llm_attempt_count < 2`, свой токен lease и ревизия).
  Рестарт, конфликт и повтор ведущего лимит не обнуляют. Сбой сети или таймаут (60 с, меньше lease)
  не корректируется.
- Fallback — детерминированный provider из тех же ограничений и резервов, `quality = fallback`. Причина
  записывается в `manifest.notes`: `fallback:invalid_proposal`, `fallback:llm_failed` или `fallback:llm_limit`.
- Устаревший ответ: финальная транзакция проверяет ревизию мира, токен, ревизию владения и срок lease. Ответ,
  пришедший после перехвата фазы, ничего не записывает.
- Каждый вызов пишется в `LlmCall` с `purpose = scene_generation`: модель, токены, стоимость, ошибка.
- Модель включается настройкой кампании `scene_generation_llm`. Без неё подготовка детерминированная;
  включает её интерфейс поставки 6.

## 3. Проверки

- принятый ответ даёт имена и описания, `quality = normal`, один вызов в `LlmCall`, схема строгая;
- невалидный ответ получает одну корректирующую попытку; два невалидных — fallback без третьего вызова;
- исчерпанный до рестарта лимит — fallback без вызова; ошибка модели — fallback без корректировки;
- без настройки модель не вызывается;
- ответ после потери lease ничего не записывает.

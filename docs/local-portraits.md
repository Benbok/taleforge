# Локальные портреты через ComfyUI

Генератор подключается к существующему ComfyUI по HTTP. Он отправляет одно задание, ждёт свою картинку и сохраняет её в защищённое хранилище Taleforge. Повторные нажатия и редактирование героя обрабатываются как у облачного генератора. Облачного fallback нет.

В `.env` рабочей копии или окружении сервера:

```dotenv
PORTRAIT_PROVIDER=comfyui
PORTRAIT_COMFYUI_URL=http://127.0.0.1:8188
PORTRAIT_COMFYUI_TIMEOUT_SEC=600
```

Перезапустите Taleforge после изменения настроек. `PORTRAIT_MODEL` относится к Gemini; локальный checkpoint задаётся в API-workflow. Для возврата в облако установите `PORTRAIT_PROVIDER=gemini`.

## Автоматический перевод русского описания

Для ComfyUI описание с кириллицей автоматически переводится на английский технической моделью выбранного `LLM_PROVIDER`. Используется соответствующий `GEMINI_TECHNICAL_MODEL`, `DEEPSEEK_TECHNICAL_MODEL`, `CLAUDE_TECHNICAL_MODEL` или `LOCAL_TECHNICAL_MODEL`; у локальной модели учитывается `LM_STUDIO_API_BASE`. Переводчик получает только внешность, образ и характер, используемые для картинки; анкета и сохранённое описание героя не меняются. Модель готовит краткое описание, сохраняя вид, волосы, глаза, одежду и отличительные черты. Само изображение создаётся локально.

Английский текст не отправляется переводчику. Последние128 успешных переводов хранятся в памяти процесса, чтобы повторные варианты изображения не требовали новых запросов перевода. Если ответ пустой, оборван, заблокирован или осталась кириллица, ComfyUI не запускается, прежний портрет сохраняется. Google Translate и дополнительные зависимости не используются: пробные запросы Google вернули429, после чего по указанию пользователя выбран перевод через техническую модель.

Настройка `PORTRAIT_TRANSLATION_TIMEOUT_SEC` ограничивает ожидание модели и очереди переводов:20 секунд по умолчанию (от1 до60). Записи журнала сохраняются вне отменяемого ожидания модели, чтобы таймаут не прерывал транзакцию. Перевод учитывается отдельной записью `hero_portrait_translation` с токенами, стоимостью и признаком известности тарифа; стоимость входит в фазу создания. У облачной технической модели этот текстовый запрос может быть платным. Кэшированные переводы новых вызовов и расходов не создают.

Для Docker укажите `http://host.docker.internal:8188`; ComfyUI должен слушать доступный контейнеру интерфейс. Тестовый запуск слушает только `127.0.0.1`. Подключение контейнера потребует отдельного запуска ComfyUI с подходящим адресом.

## Workflow

Проектная копия: `content/workflows/portrait-realvisxl-api.json`. Использует установленный `RealVisXL_V5.0_fp16.safetensors`, 1024×1024, 30 шагов, CFG 5, dpmpp_2m/karras. Положительный и отрицательный промпты адаптированы к игровым портретам; исходные внешние workflow не меняются.

Можно задать `PORTRAIT_COMFYUI_WORKFLOW` на другой JSON **в API-формате ComfyUI**, не в формате редактора с массивом `nodes`. В тексте заменяется `{{prompt}}`, отдельное значение `{{seed}}` заменяется случайным целым числом. Нужен SaveImage с одной итоговой картинкой. Checkpoint должен быть установлен в ComfyUI, не в Taleforge.

Время ожидания включает очередь и скачивание, по умолчанию 600 секунд. При истечении времени, ошибке соединения или отмене запроса удаляется только своё ещё не начатое задание. Уже исполняющееся задание может закончиться в ComfyUI, но не заменяет портрет после ошибки. Глобальная остановка не вызывается, чтобы не прерывать чужую генерацию или TTS. Прежний портрет сохраняется при ошибке.

В журнале модель отмечена как `comfyui/<checkpoint>`, стоимость облачного вызова — 0; электричество и использование видеокарты не оцениваются.

## Проверка на рабочем компьютере, 29 октября 2026

До добавления перевода: первый портрет1024×1024 из английского описания создан за43 секунды, повторный с русским описанием из Docker — за24,3 секунды на RTX4050 Laptop6GB. Английское описание передало серебристые волосы и эльфийские уши; русское потеряло эти детали. После добавления перевода DeepSeek Flash подготовил английское описание за5,3 секунды, полный цикл с локальным изображением занял32,4 секунды. Новый результат сохранил серебристые волосы, зелёные глаза и эльфийские уши: `media/local-portrait-technical-preview.png`, текст — `media/local-portrait-technical-prompt.txt` (не входят в git).

Локальный Docker-сервис переключён в существующем `.superpowers/docker-compose.retirement.yml`: provider comfyui, URL `http://host.docker.internal:8188`, timeout 600. Проверено соединение из контейнера с ComfyUI, слушающим только `127.0.0.1`, без открытия сетевого интерфейса наружу. Пересоздан только app, приложение отвечает HTTP 200. Для возврата к Gemini уберите эти три параметра из override или задайте там `PORTRAIT_PROVIDER: gemini` и пересоздайте app.

ComfyUI запущен отдельным скрытым процессом; автозапуск при перезагрузке Windows не настроен. Можно запускать установленным `run_comfyui.bat`, когда служба остановлена. Не запускайте второй экземпляр на том же порту. Исходные workflow и checkpoint вручную не менялись; тестовый процесс пишет результаты и временные файлы в `media/comfyui*` этой рабочей копии.
